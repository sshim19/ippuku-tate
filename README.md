# 一服点て

茶碗を回す速さと、茶せんの動きがそろうと、泡がきめ細かくなるゲームです。同じ日は、だれが遊んでも同じ一服を点てます。携帯は横向きで、両手で遊びます。

## 遊び方

1. 画面を横向きにして、「点てる」を押します。制限時間は75秒です。
2. 左の指で茶碗のまわりを回し、右の指で茶せんを上下に動かします。マウスなら、片方ずつ動かすことができます。
3. 回す速さと茶せんの調子がそろっていると、泡が細かくなります。ずれると、粗い泡が残ります。
4. 20秒を過ぎれば「出す」で早めに出しても構いません。時間が来ると、そのときの泡で一服になります。

最高記録と、その日の最高記録は、この端末に保存されます。0点は記録しません。

終了画面の X と LINE のボタンから、いまの得点をそれぞれの投稿画面で共有できます。

## 開き方

ビルドは不要です。フォルダをウェブサーバーで公開するか、手元では次のように開きます。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000/` を開いてください。`file://` では動きません。
